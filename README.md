# Customer-Satisfaction-Data-Analysis
Role: Junior Data Analyst | Skill set: Excel (Pivot table/chart, Data Analysis)

• Analysed customer satisfaction data for a sandwich shop using Excel in a team of three to identify wait time frequencies and correlations between wait times and customer arrival hours.

• Used confidence intervals and other statistics to test for statistical significance and visualised trends and pattern using Pivot tables/chart for strategic decision-making.
